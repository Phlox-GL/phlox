# Phlox 0.13.29 FFI migration

- Migrated the project to canonical `calcit.cirru` and the current `calcit` CLI.
- Updated the workflow and package scripts to use `calcit calcit.cirru js`, Node 24, and current `caps --ci` dependency resolution.
- Moved touch-control and pointed-prompt dependencies to their current `main` branches.
- Added narrow FFI adapters for browser values, Pixi objects, DOM operations, numeric results, and event flags.
- Replaced nullable JavaScript property chains with explicit adapters and Option-safe field reads.

- Verified with Calcit 0.13.29: check-only passed and JavaScript code generation completed successfully.
